## ✨ About the Project

Managing personal finances doesn't have to feel complicated.

**SpendWise AI** is a personal finance dashboard project focused on making everyday money management more organized and accessible. It brings expense tracking, budgeting, savings goals, and financial information together in one interface.

The project combines a modern React application with a responsive user interface and browser-based storage for organizing financial records.

### 🎯 Project Goals

* Simplify everyday expense management.
* Make budget planning easier to understand.
* Encourage consistent savings habits.
* Present financial information in an accessible interface.
* Explore how thoughtful frontend development can improve personal finance experiences.

## 🚀 Key Features

| Feature               | Description                                                    |
| --------------------- | -------------------------------------------------------------- |
| 💳 Expense Tracking   | Organize and review transaction records.                       |
| 📊 Budget Management  | Manage budgets and monitor spending against budget limits.     |

| 💾 Browser Storage    | Store transactions, budgets, and goals locally in the browser. |
| 🔔 User Feedback      | Display contextual notifications for supported actions.        |
| 📱 Modern Interface   | Navigate a clean, dashboard-oriented user experience.          |

> **Privacy note:** Financial records are stored in the browser's local storage. They are not automatically synchronized across browsers or devices. Clearing browser site data may remove locally stored records. This project should not be treated as a secure banking application.

## 🖥️ Getting Started

Want to explore or run SpendWise AI on your computer? Follow these steps.

### Prerequisites

Install the following tools before starting:

* [Node.js](https://nodejs.org/) — use a version compatible with the project's Vite requirements.
* [Git](https://git-scm.com/)
* A terminal such as PowerShell, Command Prompt, or the VS Code terminal.

### 1. Clone the repository

```bash
git clone https://github.com/ballsohini939-alt/SpendWise-AI.git
```

### 2. Enter the project directory

```bash
cd SpendWise-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local address printed in your terminal, typically:

```text
http://localhost:5173
```

Vite may select another available port if the default port is already in use.

### 5. Create a production build

```bash
npm run build
```

### 6. Check code quality

```bash
npm run lint
```

## 🔐 Data Storage & Privacy

SpendWise AI uses browser local storage to retain supported financial records.

* Data is associated with the browser profile and website origin.
* Records are not automatically shared between devices.
* Clearing the site's local storage can remove saved records.
* This project does not replace professional financial advice or secure banking software.

**Tip:** Avoid entering real banking credentials, payment-card details, or other highly sensitive information into a development project.
